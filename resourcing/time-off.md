# Time Off Requests

The **Time Off** module helps dispatchers plan future crew capacity by tracking scheduled vacations, sick leave, and personal absences.

## Submitting a Time Off Request

Employees or managers can submit requests under **Resourcing → Time Off**:
1. Click **+ Request Time Off**.
2. Select the employee name (if submitting on behalf of a team member).
3. Choose the leave type: Vacation, Sick / Medical, Personal, or Unpaid.
4. Select the date range (single day, partial day, or multi-day range).
5. Add optional notes.
6. Submit for review.

---

## Manager Approval & Scheduling Impact

- Pending requests appear on the manager's review board.
- When reviewing a request, PrairieHQ displays existing scheduled shifts for that employee during the requested window.
- Approving a request automatically removes the employee from active crew rosters during those dates and prompts dispatchers if a crew leader or key driver requires a substitute.
